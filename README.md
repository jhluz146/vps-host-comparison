## 三个常见坑和避坑方法

### 弱密码直接删机不退款

所有套餐详情页都标注"请勿设置弱密码｜弱密码删机无退款"。弱密码指纯数字、常见单词、键盘序列（123456、password、qwerty）。

设置密码时至少包含大写字母、小写字母、数字和特殊符号，长度 12 位以上。用密码管理器生成随机密码最保险。

### Shadowsocks 协议要加中转

部分套餐标注"未加中转请勿使用 shadowsocks 协议"。直接在 VPS 上跑 SS 容易被检测特征，导致 IP 被墙或端口被封。

标准做法是在前面加一层中转（可以是国内中转服务器，或者用其他协议如 V2Ray、Trojan 套一层伪装）。现在更推荐直接用 V2Ray 或 Xray 配合 WebSocket + TLS 伪装。

### 25 端口被封无法发邮件

大多数 VPS 商家封禁 25 端口防止垃圾邮件。如果你需要 VPS 发送邮件（比如 WordPress 注册确认、找回密码），不能直接用 25 端口的 SMTP。

解决办法是用第三方邮件服务（SendGrid、Mailgun、阿里云邮件推送）的 465 或 587 端口，或者联系客服申请解封 25 端口（通常需要提供正当理由）。

## 常见问题快速解答

**买了 VPS 后如何连接和使用？**

Windows 用户用 Remote Desktop（远程桌面）连接 Windows VPS，或用 PuTTY/Xshell 连接 Linux VPS。Mac 和 Linux 用户直接用终端 `ssh root@你的IP地址`，输入密码登录。

首次登录后建议立即修改 root 密码、创建普通用户、配置防火墙、关闭不必要的服务。

**如何选择操作系统？**

建站或跑 Web 应用选 Ubuntu 22.04 LTS 或 Debian 12，稳定且软件源完整。需要用 cPanel/Plesk 等面板选 CentOS 或 AlmaLinux。Windows Server 适合跑 .NET 应用或者需要 Windows 桌面环境的场景。

大多数 VPS 商家的 Windows 授权需要额外付费，ZoroCloud 部分套餐支持 Windows，具体价格咨询客服。

**遇到问题如何联系客服？**

登录 ZoroCloud 后台提交工单，或查看官网提供的联系方式。工单系统通常比邮件响应更快。

**可以随时升级或降级套餐吗？**

可以升级套餐，补差价即可。降级通常需要在计费周期结束前申请，下个周期生效。具体操作建议先联系客服确认。

**流量超了怎么办？**

大多数套餐超流量后会限速（比如从 100Mbps 限到 10Mbps），而不是直接断网或额外计费。但具体政策以服务条款为准，建议提前预留 20-30% 流量余量。

**IP 被墙了能换吗？**

通常可以付费更换 IP，价格从几美元到十几美元不等。如果是因为违规操作导致 IP 被墙，可能不给换。预防 IP 被墙的办法是不在 VPS 上跑高风险协议，或者用中转/CDN 隔离源站 IP。

## 下单前最后确认两件事

**第一，用测试 IP 检查延迟和丢包率。**

每个系列都提供测试 IP，在你本地电脑上 ping 一下，看延迟是否可接受、有没有丢包。晚高峰（晚上 8-10 点）再测一次，有些线路白天正常、晚上就炸。

Windows 用户打开命令提示符，输入 `ping 测试IP -t` 持续监测。Mac 和 Linux 用户直接 `ping 测试IP`。延迟稳定在 150ms 以下、丢包率低于 1% 算正常。

**第二，确认流量够不够用。**

VPS 的月流量是双向计算的，下载 + 上传都算。如果不清楚自己的应用会消耗多少流量，可以先选流量配额大的套餐，用一个月后看实际消耗再调整。

一个简单估算：如果你的网站平均每个访客产生 2MB 流量（包括图片、CSS、JS、字体等），1TB 流量能支撑约 50 万访客/月。实际消耗会因页面大小、缓存策略、是否有大文件下载等因素变化。
